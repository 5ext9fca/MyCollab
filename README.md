# MyCollab — Mission 协作系统

MyCollab 是面向单个团队的协作工具。你可以发布任务（Mission）、认领工作、拆分子任务、提交成果，并由验收者确认完成。设计、资产说明、任务依赖和交付记录集中保存，方便团队知道谁负责什么、在等什么、怎样才算完成。

第一次使用请阅读 [从零开始用 MyCollab 协作开发游戏](TUTORIAL.md)，通过《星星收集员》案例练习完整协作流程。

## 开始使用

1. 向团队管理员获取网站地址，使用浏览器打开。
2. 在注册页提交申请，等待管理员批准，再使用申请时的用户名和密码登录。
3. 打开“我的工作”查看待办，或在“任务广场”寻找可认领的任务。
4. 阅读任务目标、验收标准和前置关系，确认后认领；完成制作后提交成果，由验收者通过或退回修改。

普通成员无需安装开发工具。需要自行搭建团队网站时，交由部署负责人按 [部署指南](deploy/README.md) 操作。

## 主要功能

- **任务协作**：发布、认领、退出、拆分、提交、验收与取消；支持任务类型、优先级和独立验收者。
- **设计与资产**：整理设计说明与资产需求，关联任务，用生产模板生成可认领的制作步骤。
- **计划与依赖**：设置里程碑、计划日期和前置任务，在工作台查看进度与甘特图。系统展示受阻情况，不自动排期或完成任务。
- **成果与讨论**：每轮成果与验收记录保留；成员可以评论，作者可以编辑或删除自己的评论。
- **个人工作**：查看待验收、退回、临期、逾期与需复核任务，使用通知、关注、静音和保存筛选整理日常工作。
- **计划批量修改**：选择当前页任务，预览修改并逐项查看结果；仍需具备相应编辑权限。

父任务需在有效子任务全部完成后才能提交；有未完成前置的任务也不能提交或通过验收。已完成任务需要返工时，可由有权限的成员填写原因重新打开，历史记录仍然保留。详细操作见 [教程](TUTORIAL.md)。

## 用户注册与审批

成员先申请、后登录。管理员在“管理后台”审批注册申请并查看成员；批准前申请人不能登录。申请通过后使用原密码登录，无需再次注册。

## 素材库与 Markdown

在“素材库”上传文件，或在任务、评论编辑器中使用“插入素材”。每人管理自己的素材，只有所有者可以删除；其他已登录成员可以查看任务中引用的文件。

- 任务说明、验收标准、成果说明和评论可引用自己的素材或网页链接，不能引用他人素材或本机文件路径。
- 默认允许上传 `png/jpg/jpeg/gif/webp/pdf/zip/txt/md`，单文件上限 20 MB；实际限制以部署配置为准。
- 图片可直接查看，其他文件可下载。素材只向登录成员开放。

## 本地 Agent 文本辅助

登录后在“本地 Agent”创建设备凭据，在自己的电脑运行 Runner，即可辅助润色设计与资产说明、生成生产模板、编写任务和分析验收材料。安装、绑定与排错见 [本地 Runner 使用说明](local_runner/README.md)。

生成前预览输入，生成后逐字段采纳，最后手动保存或验收。模型供应商的登录与调用在本地环境进行；使用云端模型会将输入发送给所选供应商，并可能产生费用。

### 导出为 Agent 需求文档

1. 在“本地 Agent”绑定具备“Agent 需求文档”能力的设备，并保持 Runner 运行。
2. 在任务详情或抽屉点击“导出为Agent需求文档”；多台设备可用时先选择设备。
3. 等待本地模型整理任务及关联设计、资产说明，预览后点击“下载 Markdown”。

文档包括目标、约束、实施要求、交付物、验收标准、待澄清事项和来源。此操作只整理需求，不执行代码或生成图片；没有可用设备时无法生成。

## 局域网文件互传

双方登录后打开“文件互传”：发送方选择文件并生成配对码，接收方输入配对码、核对信息后确认接收。双方保持页面打开，校验成功后由接收方点击“保存已校验文件”。支持同一账号在不同设备使用。

- 单文件最多 100 MiB，文件直接传给接收方，不存入服务器素材库。
- 首次配对需在 5 分钟内确认，会话总期限为 30 分钟；中断后重新发送。
- 局域网访问需使用浏览器信任的 HTTPS 网站；本机 localhost 体验除外。
- 浏览器或操作系统询问局域网访问权限时允许本站。连接失败时联系管理员检查双方网络和防火墙。
- 当前不提供跨网中继或后台接收；网站可访问并不意味着两台设备一定能够直传。

## 演示数据

若管理员已准备演示环境，可使用 `alice`、`bob`、`carol`、`dave`、`erin` 体验，首次创建的密码统一为 `demo12345`；已有账号密码可能已被修改。请勿使用演示账号保存需要长期保留的业务数据。

- 用 `alice` 查看待验收、临期、逾期和需复核；用 `bob` 查看退回待改、解除阻塞和个人筛选。
- 查看任务拆分、前置依赖、成果历史、工作台日期、设计资产与生产模板。
- 打开“示例导览：当前能力与边界”任务，按提示体验。

演示构建链接只是示意，不能作为真实试玩版本；没有预置私人素材。《星星收集员》教程练习需自行创建。
