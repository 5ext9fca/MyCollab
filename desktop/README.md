# MyCollab 桌面客户端

桌面客户端将任务协作和本地 Agent 管理放在同一个应用中，连接团队现有网站使用，不会在电脑上安装团队服务器。任务、素材、通知与管理功能沿用网站的账号和权限。

**当前仍处于开发阶段，尚未完成跨平台运行、安装、文件直传与界面验收，不是已正式发行的客户端。** 以下说明对应当前实现，供取得开发包的用户了解操作；可用安装包及受测系统以维护者实际提供的信息为准。目标为 Windows x64、macOS Apple Silicon 与 Intel；macOS 要求 13 或以上，Windows 最低受测版本尚未确定。

仍使用 `MyCollab Companion.app` 的用户请阅读 [旧版伴侣指南](LEGACY_COMPANION.md)。旧伴侣只管理 Agent，不包含协作页面。

## 连接与登录

1. 向维护者取得适合本机系统和架构的客户端。开发包不等同于正式签名、公证的发行包，不要关闭系统安全设置来运行来源不明的软件。
2. 首次打开，在“桌面设置”的“协作服务器”填写管理员提供的网站根地址，例如 `https://collab.example.com`，然后保存并前往登录。
3. 使用已获管理员批准的账号登录。任务发布、认领、提交、验收和素材操作见 [协作教程](../TUTORIAL.md)。

服务器通常必须使用 HTTPS；仅本机地址允许 HTTP。新客户端暂不提供旧伴侣的“内部 CA 证书”设置，使用内部证书的网站应先向维护者确认兼容性，不应跳过证书验证。

切换服务器会停止本机 Runner、退出当前登录并重新加载页面。请先保存编辑、结束文件传输。退出客户端后再次打开需要重新登录；本期不支持离线编辑与自动同步，断网时不能把未保存内容视为已保存。

## 绑定与运行本地 Agent

普通协作无需安装模型工具。需要本地 Agent 辅助时，客户端已包含 Runner 所需的运行环境，但仍需自行安装已验证的 OpenCode 2.1.3，并完成模型供应商登录。安装与供应商配置见 [Runner 使用说明](../local_runner/README.md)。客户端不包含模型账号或额度，使用云端模型可能产生费用。

1. 登录后进入“本地 Agent”，填写设备名称并点击“创建设备凭据”。设备令牌仅创建时显示，不要在此处填写供应商密钥。
2. 在本机绑定区域选择设备，填写设备令牌、OpenCode 模型和可执行文件路径。新创建设备会自动填入本次令牌；推荐填写可执行文件的完整路径，避免从应用启动时找不到命令。
3. 保存绑定。设备归属通过服务器核验后加密保存在本机；保存不会启动模型。以后修改同一设备的模型或路径时，令牌可以留空。
4. 在 Runner 已停止时点击“自检（不调用模型）”。自检检查 OpenCode 和服务器状态，不验证供应商额度或实际模型调用成功率。
5. 点击“启动 Runner”，再在协作页面发起辅助请求。启动需要在线核验身份。生成结果仍需人工审阅、采纳和保存，不会自动完成任务或验收。

本次客户端已核验当前登录身份后，断网仍可做本机自检；这不意味着完全离线时可以首次登录、绑定或启动。系统凭据保护不可用时不会退回明文保存，请联系维护者排查。

## 运行、停止与结果恢复

关闭窗口会隐藏到托盘或菜单栏，已启动的 Runner 可以继续运行。点击图标可重新显示窗口；选择托盘菜单“退出”会等待 Runner 停止。切换服务器、退出登录或重新绑定设备也会先停止 Runner；停止失败时应保留当前会话并排查，不能认为应用已经安全退出。

“登录系统后启动 MyCollab”默认关闭，开启后只自动打开客户端，不自动启动 Runner 或模型。重新打开客户端后，登录并手动启动 Runner。

- **待回传结果**：本机已取得结果但尚未完成回传。重新启动后会尝试发送同一份结果，不因此再次调用模型；停止时显示的是本机已有的摘要。
- **回传被拒绝**：请求已结束、内容变化或服务器不再接受结果。结果不会自动覆盖网站内容，本机保留受数量和最长 24 小时限制。
- 模型执行中途停止不自动重新生成；如需重试，在协作页面明确发起新请求。

不要让命令行 Runner、旧伴侣和新客户端同时使用同一设备。不要通过复制本机凭据来共享设备；不同账号、服务器或设备的结果不会自动迁移。

## 从旧 macOS 伴侣迁移

1. 停止并退出旧伴侣，关闭其开机启动；新客户端需单独安装，不能通过旧伴侣直接升级替换。
2. 在新客户端登录原服务器的原账号。在尚未保存本机绑定时，进入“本地 Agent”点击“导入旧伴侣配置”。
3. 导入成功后自检，再手动启动 Runner。新客户端会复用旧配置对应的待发结果与运行锁；旧 Runner 未停止时无法同时运行。

仅支持当前用户的默认旧配置，并要求文件仅本人可读写。使用自定义 CA 的旧配置暂不能导入。导入失败保留原文件；成功也不会删除旧配置或待发结果，不要在结果恢复前自行清理旧文件。实际旧版迁移交互尚未验收。

## 文件互传与更新

文件互传沿用网站的配对、接收确认和校验流程，双方需保持传输页面打开；不提供后台接收或跨网中继。在“桌面设置”允许局域网访问，并按系统提示授权。内置浏览器内核不保证网络、防火墙或系统权限一定允许直传，真实双机互通仍待验收。

“客户端更新”提供分开的检查、下载和安装操作。检查与下载不会停止 Runner；选择“停止 Runner 并安装更新”前先保存编辑并结束传输。安装会停止 Runner 并退出客户端，更新后不会自动启动模型。普通退出不会自动安装已下载更新。

开发包禁用在线更新。正式更新还依赖维护者配置更新服务、签名与公证；当前尚未完成真实发行与升级验证。没有更新源时向维护者取得下一版本，不应把“下载完成”理解为已经安装成功。

## 常见问题

- **找不到 OpenCode / CLI 不可用**：检查完整路径及安装版本；从终端能够运行命令，不保证应用也能找到同一个命令。
- **服务器不可用**：检查根地址、网络及证书；离线自检仍可显示本机 CLI 状态。
- **绑定失败或设备失效**：确认服务器与账号正确，设备未撤销或过期，令牌属于所选设备；必要时重新创建设备。不要把旧设备待发结果直接交给新设备。
- **停止失败**：保留当前客户端并联系维护者排查；不要立即启动另一个宿主接管同一设备。
- **连接中断或页面报错**：确认服务器恢复后重试，并核对网站中实际保存的内容。未提交的编辑不会作为离线草稿自动同步。
